# 영상 검토·승인 서버

개인 운영자용 카카오톡 영상 검토함. 현재 단계는 승인 서버이며 **자동 제작·Metricool 게시 담당 프로그램은 아직 연결되지 않았습니다.** 서버 배포만으로 유튜브·인스타그램에 게시되지 않습니다.

## 기능

- 관리자 로그인, 만료되는 세션, 요청 위조 방지
- MP4 업로드(50MB 이하), 휴대폰 미리보기와 영상 구간 요청
- 제목·설명과 함께 영상 검토, 승인 또는 수정 요청
- 새 버전 업로드 시 기존 링크와 승인 무효화
- 카카오 로그인 및 ‘나와의 채팅’ 검토 링크 전송
- 앱 키·카카오 토큰의 암호화 저장
- 별도 게시 담당 프로그램용 대기열 API. 승인한 영상만 한 번 인계
- 플랫폼별 결과 기록. 일부 결과 누락 시 자동 재시도하지 않고 확인 대기

## 배포 전 상태

2026-11-07: 로컬 WSGI 동작 검사 17개 통과. 실제 카카오 로그인/메시지, Render 배포/헬스 체크, 휴대폰 실기기, 실제 게시 연동은 아직 검증 전입니다. 이 저장소에는 영상·앱 키·사용자 토큰이 없습니다.

## Render 구성

`render.yaml`: Singapore / Python 웹 서비스 1개 / `0.5c-512mb` / 영구 디스크 1GB. 승인·토큰·영상은 `/var/data` 아래 보관합니다. 단일 인스턴스 전용. 자동 배포/동기화는 꺼두고 승인받은 변경만 배포합니다.

공식 가격표 기준 기본 구성 예상: 웹 서비스 USD 7/월 + 디스크 USD 0.25/월 = USD 7.25/월. 세금·환전·초과 트래픽·워크스페이스 유료 요금·별도 게시 도구 비용은 별도입니다. 실제 결제 화면에서 다시 확인하고 비용 및 배포 승인을 받은 뒤 적용합니다.
가격 출처: https://render.com/pricing

서비스 생성 시 `ADMIN_PASSWORD`는 16자 이상의 별도 비밀번호로 직접 입력하세요. `APP_SECRET`과 `PUBLISHER_TOKEN`은 Render가 생성합니다. 비밀 값은 GitHub나 채팅에 쓰지 마세요. APP_SECRET을 변경하면 기존 토큰을 복호화할 수 없으므로 카카오를 다시 연결해야 합니다.

## 최초 연결 순서

1. Blueprint 계획을 검토하고 비용·배포 승인을 받습니다.
2. Render 대시보드에서 ADMIN_PASSWORD를 직접 설정하고 배포합니다.
3. 서버의 `/healthz` 응답과 HTTPS 접속을 확인합니다.
4. 실제 서버 주소 + `/kakao/callback`을 카카오 REST API 키의 로그인 리다이렉트 URI에 등록합니다.
5. 카카오 ‘제품 링크 관리’의 웹 도메인에 실제 서버의 HTTPS 기본 주소를 등록합니다.
6. 서버에 관리자 로그인 → REST API 키·클라이언트 시크릿을 비공개 입력 → 카카오 로그인 및 talk_message 동의.
7. 검토용 MP4를 등록하고 나와의 채팅으로 검토 링크를 보내 시험합니다.
8. 휴대폰에서 로그인 → 미리보기 → 승인/수정 요청. 이 단계까지는 게시되지 않습니다.
9. 게시 담당 프로그램을 추가 연결할 때 게시 대상 계정·YouTube 아동용 여부·시간대·게시 시각·실패 처리부터 확정합니다. 사용자 승인 없는 영상을 게시하지 않습니다.

## 게시 담당 프로그램 API 계약

인증: `Authorization: Bearer <PUBLISHER_TOKEN>`.
`POST /api/claim`은 승인 대기열에서 한 항목을 원자적으로 가져와 publishing 상태로 바꿉니다. 반환값: id, version, digest, title, caption, providers, 1시간 만료 미디어 URL. 대상이 없으면 JSON null.
`POST /api/complete`: JSON `{id, version, receipts: {youtube: "scheduler-post-id", instagram: "scheduler-post-id"}}`. 두 결과가 확인되면 scheduled, 일부가 빠지면 needs_attention. 이 API는 직접 예약하거나 게시하지 않습니다. 예약 담당 프로그램은 Metricool 응답을 저장한 뒤에만 결과를 보고해야 합니다. 처리 중 끊긴 요청은 재전송 전에 Metricool 예약 목록을 확인해 중복 게시를 방지해야 합니다.

새 버전은 검토 화면의 ‘새 영상으로 교체하고 다시 검토’를 사용합니다. 이미 인계/예약된 영상은 교체를 막습니다. 기존 예약 취소·변경은 별도 확인 절차가 필요합니다.

Gunicorn은 Linux 배포용입니다. 관리자 비밀번호를 알 수 없는 사람은 영상을 재생하거나 승인할 수 없습니다. 영상과 승인 기록의 장기 보관·정리는 운영자가 관리해야 하며 1GB를 초과하면 디스크 증설 또는 별도 보관이 필요합니다.
